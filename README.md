# 青程 · 学习日程

面向手机端的轻量日程 PWA，用于管理六级备考、实验催办和作业。

## 功能

- 今日任务与完成进度
- 六级、实验、作业分类筛选
- 新增、完成和删除日程
- 本地持久化与深色模式
- 可安装到手机主屏幕并离线打开

## 本地预览

```bash
python3 -m http.server 8000
```

浏览器打开 `http://localhost:8000`。

## GitHub Pages

仓库设置中选择 **Pages → Deploy from a branch → main / root** 即可发布。

## M3E Canvas

`design.json` 是对应的 Material 3 Expressive 原型源文件，可在 M3E Canvas 中继续编辑。

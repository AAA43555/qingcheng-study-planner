# 薇薇安小姐我是你的狗

面向手机端的轻量日程 PWA，用薇薇安督促你推进每一项计划。

## 功能

- 今日任务与完成进度
- 分类可新增、改名、换色和删除
- 新增、完成和删除日程
- 新增任务可选择毒舌、严厉、温柔或只提醒四种训话模式
- 支持每 N 天/周/月循环，可设置开始和结束日期，完成后自动生成下一期
- 高、中、低优先级标记与排序
- 到期时或提前 10/30/60 分钟的网页通知提醒
- 一键写入 iPhone 系统日历，网页关闭后仍由系统提醒
- 薇薇安督学互动：未完成时催办，完成今日任务后解锁摸头与害羞表情
- 可选一次完成或三阶段任务，点击卡片逐步开花并更新总进度
- 批量同步未完成任务到 iPhone 日历，可配合系统日历桌面组件显示
- 本地持久化与深色模式
- 可安装到手机主屏幕并离线打开

> 提醒由浏览器在页面运行期间调度。若手机系统完全终止网页，纯静态 GitHub Pages 无法保证后台准时推送；可靠的闭屏推送需要额外的 Web Push 服务。

## 本地预览

```bash
python3 -m http.server 8000
```

浏览器打开 `http://localhost:8000`。

## GitHub Pages

仓库设置中选择 **Pages → Deploy from a branch → main / root** 即可发布。

## M3E Canvas

`design.json` 是对应的 Material 3 Expressive 原型源文件，可在 M3E Canvas 中继续编辑。
